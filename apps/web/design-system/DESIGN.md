## Brand & Style

Kinetic Obsidian is an ultra-refined, high-performance product aesthetic built for elite creators, video engineers, and post-production studios. It balances industrial technical precision with sleek, editorial luxury. 

The visual voice is authoritative, low-friction, and cinematic. The aesthetic fuses **Minimalist structural foundations** (clean neutral canvases, deep contrast, micro-monospaced technical metadata) with **Radiant Glassmorphism** (rich jewel-toned glowing hero meshes, frosted backdrop blurs, and pill-shaped floating navigations). It evokes confidence, zero-latency speed, and master-grade polish.

## Colors

The core palette relies on a stark, bright foundational light surface (`#fafafa` and `#ffffff`) anchored by profound onyx and obsidian tones (`#0a0a0c`, `#111215`) for high contrast text and dark container blocks.

- **Primary (`#ff334b`)**: Energetic studio crimson/red accent used for critical signals, active states, indicators, and primary visual anchors.
- **Secondary (`#0a0a0c`)**: Absolute near-black used for primary interactive triggers (floating pills, dark cards, footer, key headlines).
- **Tertiary (`#103b32`)**: Deep emerald/forest tone anchoring the multi-stop mesh gradients alongside warm amber and deep navy.
- **Neutrals**: Meticulously tiered from pure ink `#0d0f12` down to technical slate `#64676f` and razor-thin container borders `#e4e6ea`.

## Typography

Typography pairs tight, geometric sans-serif forms (**Inter**) with high-density developer monospace (**JetBrains Mono**).

- **Headlines & Display**: Tight negative tracking (`-0.02em` to `-0.04em`) with compact line heights gives hero statements an assertive, editorial broadcast presence.
- **Body**: Clean, high-legibility sans running at relaxed line-height ratios (1.5x) for documentation and narrative copy.
- **Monospace Metadata & Badges**: JetBrains Mono serves technical specs (e.g., file sizes, codecs `ProRes 422`, latencies `24ms`, and direct API statuses), grounding the aesthetic in engineering authenticity.

## Layout & Spacing

The layout employs a centered **Fixed Grid system** bounded at a maximum width of `1152px` (`max-w-6xl`) with dynamic horizontal padding:
- **Mobile (<768px)**: 16px (`px-4`) side margins, single-column vertical flows.
- **Tablet / Desktop (≥768px)**: 24px (`px-6`) side margins scaling into 2-column asymmetric deep-dive sections, 3-column media update rows, and 4-unit dark card grids.

Vertical rhythm relies on generous section separation (80px to 112px; `py-20` to `py-28`) balanced against dense, micro-spaced UI cards (8px to 16px internal padding).

## Elevation & Depth

Visual depth is achieved through layered structural tiers rather than heavy traditional drop shadows:

1. **Floating Navigation Bar**: Elevated above the viewport with `bg-[#0d0f11]/90`, `backdrop-blur-md`, a hairline `border border-white/10`, and an ambient `shadow-2xl`.
2. **Glowing Hero Mesh & Glass Windows**: The primary visual is inset inside a double-border rim (`bg-gradient-to-b from-neutral-300 via-neutral-200 to-transparent`) hosting an internal frosted container (`bg-black/40`, `backdrop-blur-xl`, `border-white/20`).
3. **Card-Level Elevation**: Default cards use crisp flat backgrounds (`#ffffff` or `#fafafa`) resting on hairline borders (`border-neutral-200/80`) paired with gentle ambient `shadow-sm` or `shadow-md`.
4. **Rich Dark Surfaces**: 2x2 grid features use high-depth dark panels (`#111215`) layered with gradient overlays and low-opacity chromatic radial glows (`blur-lg`).

## Shapes

The interface embraces a hyper-rounded, capsule-driven shape language (`roundedness: 3`):

- **Buttons, Navbars & Pills**: Full pill radius (`rounded-full`, 9999px) for search bars, navigation containers, status tags, and primary action triggers.
- **Content Cards & Media Panels**: Curved at `1.5rem` (`rounded-2xl`) or `1.75rem` (`rounded-3xl`), introducing a friendly, modern tech silhouette that balances the sharp dark typography.
- **Micro-Badges & Code Tokens**: Squared with gentle rounding (`rounded-lg`, 6px - 8px) to retain technical discipline.

## Components

### Buttons
- **Primary Action (Dark)**: Full pill (`rounded-full`), background `#000000` or `#0d0f11`, text `#ffffff`, micro-padding (`px-4 py-1.5` for compact, `px-6 py-3` for hero), subtle hover lighten (`hover:bg-neutral-800`), transition duration 200ms.
- **Secondary Action (Light/Outline)**: Full pill (`rounded-full`), background `#ffffff`, text `#0d0f12`, border `border-neutral-300`, hover background `#f4f4f5`.
- **Accent Action**: Background `#ff334b`, text `#ffffff`, hover `#e6243b`.

### Chips & Filter Pills
- Enclosed in an integrated track (`bg-neutral-100`, `rounded-full`, `p-1`).
- Active pill: `#000000` background, white text, subtle elevation shadow.
- Inactive pills: Transparent background, `#64676f` text, hover transition to `#0d0f12`.

### Cards & Panels
- **Light Vault Cards**: Background `#ffffff`, border `border-neutral-200/80`, radius `rounded-2xl`, internal padding `p-5` or `p-6`.
- **Glassmorphic Cards**: Gradients ranging from warm ochre to cool teal, overlay `backdrop-blur-md`, white typography, and inset white/20 borders.
- **Dark Feature Blocks**: Background `#111215`, inner gradient masks, subtle chromatic blurs, monospace category stamps in bright accents (Amber, Sky, Emerald).

### Lists & File Rows
- Dividers using hairline `divide-neutral-100`.
- File extension icons: Fixed `w-6 h-6`, `rounded-md`, technical monospaced text (`10px`), tinted background matching file category (`bg-red-50 text-red-600` for SRT, `bg-neutral-100` for MOV).
- Metadata pinned right: Monospaced muted slate text (`JetBrains Mono`, `text-[11px]`).

### Progress & Status Indicators
- **Track**: `w-full bg-white/20 h-2 rounded-full overflow-hidden`.
- **Fill**: High-energy gradient `from-yellow-400 via-brand-accent to-pink-500`.
- **Live Event Beacon**: `w-2 h-2 rounded-full bg-brand-accent animate-pulse`.
